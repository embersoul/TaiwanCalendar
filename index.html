Taiwan Calendar API

歡迎使用台灣政府行政機關辦公日曆 API！本 API 提供中華民國政府行政機關的辦公日曆資料，包含日期、星期、是否放假及備註。

API 端點

  • 當前年份日曆: /api/taiwan-calendar
    範例: /api/taiwan-calendar
    返回當前年份（例如 114 年，2025 年）的日曆資料。
  • 指定年份日曆: /api/taiwan-calendar/
    範例: /api/taiwan-calendar/113
    返回指定年份（例如 113 年，2024 年）的日曆資料。

回應格式

[
    {
        "date": "20250101",
        "day_of_week": "三",
        "is_holiday": 2,
        "note": "開國紀念日"
    },
    ...
]

備註

- is_holiday: 0 表示上班日，2 表示放假日。
- 資料來源: data.gov.tw。
